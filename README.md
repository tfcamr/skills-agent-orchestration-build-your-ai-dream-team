# Project Pulse Dashboard

## Project Pulse Story
Project Pulse is an automated team status updates and productivity tool designed to streamline project tracking. The application orchestrates multiple specialized AI agents to collaborate seamlessly, detect timeline conflicts, and generate formatted status reports. 

This dashboard visualizes the key project metrics, ongoing tasks, and potential roadblocks compiled by the agent team, providing managers and stakeholders with real-time insight into the project's health.
